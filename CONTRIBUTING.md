# Contributing to ContextPrism

Thank you for contributing to ContextPrism!

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/1997agarwal/ContextPrism.git
   cd ContextPrism
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run local dev server:**
   ```bash
   npm run dev
   ```

## Contribution Principles
- Adhere to the **Clean, Intuitive & Modern 2026 Light Theme** standard for all UI contributions.
- Maintain the 4-File Parity standard when adding core architectural features.
- Ensure all TypeScript checks pass before submitting pull requests.
